Trust boundary

The consent boundary

  • The confirmation nonce travels only in _meta — the model never sees it.
  • Recommendation is not authorization: confirming takes a separate direct click.
  • Mandates expire; duplicate confirms stay idempotent; declines create no order.
  • Merchant failure after authorization enters reversal.

Payment rail

Approve, decline, and reverse semantics behind one adapter seam — no card credentials ever enter Woven, and a production processor drops into src/payment.ts.
